OTP fix notes

1. This source ZIP intentionally excludes .env, academic.db, and node_modules.
2. Copy .env.example to .env and add your own settings/secrets.
3. Run: npm install
4. Run: npm start
5. Existing database/user data are not included. To preserve your current data, back up your existing academic.db before replacing anything.

OTP changes:
- New OTP requests invalidate older unused codes for the same user and purpose after successful delivery.
- OTP input is normalized to digits before checking.
- A code is expired at its exact expiry timestamp.
